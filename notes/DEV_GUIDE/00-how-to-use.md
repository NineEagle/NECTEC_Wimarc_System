# บทที่ 00 — คู่มือนี้ใช้อย่างไร

> อ่าน 5 นาที

## WiMaRC คืออะไร

WiMaRC คือระบบตรวจวัดและจัดเก็บสภาวะแวดล้อมในสวนทุเรียน มีสถานีวัดจริง **30 จุด**
ในจันทบุรี ระยอง และตราด แต่ละจุดมีอุปกรณ์ 2 ตัว:

- **สถานีหลัก** (`wimarc1`, `wimarc2`, …) วัดอากาศ — อุณหภูมิ ความชื้น ลม ฝน แสง ความกดอากาศ
- **สถานีลูก** (`wimarc1c`, `wimarc2c`, …) วัดดิน — ความชื้นดินและอุณหภูมิดินที่ความลึก 15 และ 30 ซม.

อุปกรณ์ยิงข้อมูลเข้าเซิร์ฟเวอร์ตลอดเวลา แล้วเว็บ `wimarc.in.th` เอาข้อมูลนั้นมาแสดง
ให้เจ้าของสวนและผู้ดูแลระบบดู พร้อมพยากรณ์อากาศ กราฟย้อนหลัง แผนที่ และการดาวน์โหลดข้อมูล

หน้าที่ของคุณคือ **ดูแลและพัฒนาเว็บตัวนี้ต่อ** — เพิ่มหน้าใหม่ เพิ่มค่าที่แสดง แก้บั๊ก
และส่งขึ้นเครื่องจริง คู่มือเล่มนี้พาไปทีละขั้นตั้งแต่ยังไม่มีอะไรในเครื่องเลย

## อ่านจบแล้วคุณจะทำอะไรได้

- รันระบบทั้งชุดในเครื่องตัวเองได้ และรู้ว่าตอนรันอยู่นั้นมีอะไรทำงานอยู่บ้าง
- อ่านโค้ดหน้าใดก็ได้ แล้วบอกได้ว่า "ตัวเลขบนการ์ดนี้มาจากไฟล์ไหน ตารางไหน"
- เพิ่มหน้าใหม่พร้อมเมนู เพิ่มค่าจากฐานข้อมูลขึ้นหน้าจอ และเพิ่มฟีเจอร์ที่มีปุ่มเพิ่ม/แก้/ลบครบ
- สั่ง build และ deploy ขึ้นเครื่องจริง พร้อมตรวจว่าไม่พัง และย้อนกลับได้ถ้าพัง
- รู้กฎการบันทึกงานของโปรเจกต์นี้ ซึ่งสำคัญมาก เพราะคนที่มาต่อจากคุณจะอ่านจากตรงนั้น

## สิ่งที่คู่มือนี้ไม่สอน

ไม่สอนการเขียนเฟิร์มแวร์ ESP32 ไม่สอนการติดตั้งเสาในสวน และไม่ลงลึกทฤษฎี React
ถ้าอยากรู้ฝั่งฮาร์ดแวร์และการรับข้อมูลจากอุปกรณ์ ให้อ่าน `notes/TRAINING_2026-09-08.html`
ซึ่งเป็นเอกสารคนละเล่มกับเล่มนี้

## วิธีอ่านที่ได้ผลที่สุด

เปิดคู่มือไว้จอหนึ่ง เปิด VS Code ไว้อีกจอหนึ่ง แล้ว **พิมพ์ตามทุกคำสั่ง** อย่าอ่านผ่าน ๆ
บทที่ 10–12 คือของจริง ให้ลงมือทำแล้วดูผลบนหน้าเว็บทุกครั้ง เห็นผลด้วยตาแล้วจะจำได้เอง

## ข้อตกลงในการเขียนคู่มือเล่มนี้

| สัญลักษณ์ | ความหมาย |
|---|---|
| `code แบบนี้` | ชื่อไฟล์ ชื่อฟังก์ชัน หรือคำสั่งที่พิมพ์ได้ตรง ๆ |
| บล็อกโค้ดที่ขึ้นต้นด้วย `#` | ความคิดเห็นอธิบาย ไม่ต้องพิมพ์ |
| `<ค่าแบบนี้>` | ให้แทนด้วยค่าจริงของคุณ |
| 🔴 ระวัง | จุดที่พลาดแล้วระบบจริงพัง หรือเสียเวลาหาสาเหตุนาน |

## ก่อนเริ่มบทถัดไป

โปรเจกต์นี้มีบันทึกการทำงานสะสมไว้ในโฟลเดอร์ `notes/` ทุกครั้งที่เริ่มงานใหม่
คนที่นี่จะอ่าน 4 ไฟล์นี้ก่อนเสมอ (ระบุไว้ใน `CLAUDE.md` ที่รากโปรเจกต์):

```
notes/DEPLOYMENT_NOTES.md   ← ทุก feature/config ที่ deploy แล้ว (ตอนนี้ 86 รายการ)
notes/BUGS.md               ← bug ที่เคยพบและแก้แล้ว (ตอนนี้ 27 รายการ)
notes/SECURITY.md           ← ช่องโหว่และการปิดช่องโหว่
notes/IDEAS.md              ← ไอเดียและแผนที่ยังไม่ได้ทำ
```

ยังไม่ต้องอ่านทั้งหมดตอนนี้ แค่รู้ว่ามีอยู่ เพราะบทที่ 15 จะกลับมาพูดเรื่องนี้อีกครั้ง
พร้อมกฎว่าคุณต้องเขียนอะไรลงไปบ้างหลังทำงานเสร็จ
