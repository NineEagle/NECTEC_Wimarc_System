# คู่มือพัฒนาเว็บ WiMaRC — ฉบับเริ่มจากศูนย์

คู่มือเล่มนี้เขียนให้คนที่ **ไม่เคยเขียนเว็บมาก่อนเลย** อ่านแล้วลงมือพัฒนาและดูแลระบบ
[wimarc.in.th](https://www.wimarc.in.th) ต่อได้จริง ทุกคำสั่ง ทุกชื่อไฟล์ ทุกค่าคอนฟิก
ในเล่มนี้ตรวจจากโค้ดที่รันอยู่บนเซิร์ฟเวอร์จริง ไม่ใช่ตัวอย่างสมมติ

- **ผู้อ่าน:** คนที่จะมารับช่วงพัฒนาเว็บ WiMaRC ต่อ (ไม่ต้องมีพื้นฐานเว็บมาก่อน)
- **ระบบที่อ้างอิง:** Next.js 16 + FastAPI + PostgreSQL 16 + Apache บน Docker
- **เวลาอ่านจบพร้อมลองทำ:** ประมาณ 1 วัน
- **ปรับปรุงล่าสุด:** 8 กันยายน 2569

## วิธีอ่าน

1. อ่านเรียงจากบท 00 ไปเรื่อย ๆ **ห้ามข้ามบท 03–05** เพราะบทหลังจากนั้นถือว่าเครื่องคุณรันระบบได้แล้ว
2. เปิดคู่มือไว้จอหนึ่ง เปิด editor ไว้อีกจอหนึ่ง แล้ว**พิมพ์ตามทุกคำสั่ง** อย่าอ่านผ่าน
3. บท 10–12 คือของจริง ให้ลงมือทำแล้วดูผลบนหน้าเว็บทุกครั้ง

## สิ่งที่คู่มือเล่มนี้ไม่ครอบคลุม

- เฟิร์มแวร์ ESP32, การติดตั้งเสาในสวน, การรับข้อมูลฝั่ง PHP → อ่าน `notes/TRAINING_2026-09-08.html`
- รายละเอียด endpoint ทุกตัวพร้อมตัวอย่าง request/response → อ่าน `notes/API_ENDPOINTS.md`
- ที่มาของสูตรคำนวณแต่ละค่า → อ่าน `notes/DATA_LOGIC.md`
- ประวัติการ deploy / บั๊กที่เคยเจอ / ช่องโหว่ที่ปิดไปแล้ว → อ่าน `notes/DEPLOYMENT_NOTES.md`, `notes/BUGS.md`, `notes/SECURITY.md`

## หมายเหตุสำหรับคนที่จะเอาไปจัดเป็นเล่ม

- ไฟล์ทุกบทเป็น Markdown ล้วน เรียงตามเลขนำหน้าไฟล์ได้เลย ไม่มีการอ้างอิงข้ามบทแบบที่ต้องจัดลำดับใหม่

- ระดับหัวข้อ: `#` = ชื่อบท, `##` = หัวข้อหลัก, `###` = หัวข้อย่อย ใช้ได้ตรง ๆ กับการทำสารบัญอัตโนมัติ
- ไม่มีรหัสผ่าน คีย์ หรือค่า secret จริงในเล่มนี้ ตั้งใจให้แจกจ่ายภายในทีมได้อย่างปลอดภัย
